### 2.3 URL and language structure

T1.1.3.2. Locale prefixes are fixed by [DEC-002](decisions.md). The slug language is a proposal in [DEC-035](decisions.md) and is not approved. The strings in the mapping table follow that proposal so the architecture can be reviewed. They are not the final spellings. After DEC-035 is approved, each page's Figma design sets the final spelling (T1.2.2.2). English names in the table are working titles for the mapping, not approved copy.

#### 2.3.1 Locale pattern

Persian (`fa`) is the default. English (`en`) has the same pages.

| | Persian | English |
|---|---|---|
| Homepage | `/` | `/en/` |
| Any other page | `/{slug}/` | `/en/{slug}/` |

There is no `/fa/` prefix. `{slug}` is one path segment. The sitemap hierarchy in §2.2 does not add extra segments: PAGE-014 is one page with two parents (DEC-001), so its URL is `/{slug}/`, not a path under فروش or under PAGE-004.

#### 2.3.2 Trailing slash, canonical URL, and the language switcher

- The Persian homepage is exactly `/`. The English homepage is exactly `/en/`, with the trailing slash.
- Every other page has exactly one trailing slash.
- A request for the same path without that slash resolves to the slashed URL. `/en` resolves to `/en/`.
- The canonical URL of a page is its own locale URL: scheme, production host, and the path above, with no query string. The production host is not chosen yet (DEC-019). Persian pages are not the canonical of English pages, and English pages are not the canonical of Persian pages.
- The language switcher opens the other locale of the same PAGE-ID, using the mapping below. Full parity (DEC-002) means every Phase 1 page has that counterpart. A missing counterpart is an error and does not ship. The switcher does not send the visitor to the homepage in its place.

#### 2.3.3 Slug language (proposed, not approved)

Proposal (DEC-035): localized slugs. The Persian URL uses a Persian slug. The English URL uses an English slug. Words are separated by a hyphen. Persian slugs use Persian letters (ی and ک, not the Arabic forms) and do not use ZWNJ. English slugs use lowercase Latin letters. The proposal does not decide the LEGO trademark question (DEC-012); the slugs follow the existing page names.

#### 2.3.5 hreflang

Each shipped page states both language versions in the document head. The language codes are `fa` and `en`. Each page includes a self-referencing entry. `x-default` points at the Persian URL of the same PAGE-ID, including on the homepage, where it points at `/`.

On `/معرفی-خدمات/` the relations are:

- `hreflang="fa"` → `/معرفی-خدمات/`
- `hreflang="en"` → `/en/services/`
- `hreflang="x-default"` → `/معرفی-خدمات/`
- `canonical` → `/معرفی-خدمات/`

On `/en/services/` the `fa`, `en`, and `x-default` targets are the same three URLs, and `canonical` is `/en/services/`. The canonical URL and the self-referencing hreflang URL are the same. A missing counterpart is not given an hreflang entry, because that page does not ship (DEC-002). The same pairs are what the XML sitemap must repeat (T1.6.4.1).

Navigation in §2.5 and §2.7 names PAGE-IDs. The path pattern is §2.3.1. The proposed strings are the mapping table, not approved slugs.

### 2.6 Mobile navigation

The mobile header does not repeat the desktop row. It keeps three controls: the logo (PAGE-001), the action تماس با ما (PAGE-008), and a menu button.

- The menu button is a button, not a link. It shows a menu icon. Its accessible name is the word for menu in the current language; the exact word is copy, not set here. `aria-expanded` follows the open state.
- Activating it opens a panel and moves focus into the panel. The page behind the panel does not scroll. The panel closes with the same button, a close control inside the panel, or Escape. Focus returns to the menu button.
- The services group is a disclosure inside the panel, not a desktop dropdown. معرفی خدمات links to PAGE-002. An expand control reveals PAGE-003, PAGE-004, PAGE-013, and PAGE-014 in place.
- The same panel then lists PAGE-010, PAGE-006, PAGE-007, and PAGE-011.
- A secondary group in the panel lists the footer-only pages, PAGE-009 and PAGE-012, so they are reachable without scrolling to the footer.
- The language switcher is inside the panel.
- The تماس با ما action stays outside the panel, beside the menu button.
- Touch and keyboard can open, move through, and close the panel. The current page is indicated.
